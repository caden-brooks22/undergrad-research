# PINN Research

This repository contains my undergraduate research and learning work related to **Physics-Informed Neural Networks (PINNs)**.

This repository is to learn the fundamentals of neural networks, PyTorch, automatic differentiation, and PINNs then applying them to PDE problems.

## Structure

* `learning/` - Practice, experiments, and notes
* `src/` - final project source code
* `results/` - Results, figures, and analysis

## Current Goals

* Learn neural network fundamentals
* Learn PyTorch
* Understand automatic differentiation
* Learn the basics of PINNs
* Learn and solve PDEs numerically
* Finally apply PINNs to research problems

This is an ongoing undergraduate research project, so the repository will change as I learn and develop new ideas.
